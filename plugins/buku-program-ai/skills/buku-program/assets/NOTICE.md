# Notis imej contoh

Kedua-dua JPEG dalam folder ini dibekalkan pemilik projek dan diterbitkan dengan izinnya sebagai rujukan visual buku program. Nama, logo dan kandungan acara asal tidak boleh dianggap sebagai maklumat program pengguna.

Lesen MIT projek meliputi teks panduan dan kod ujian sahaja; ia tidak memberikan hak terhadap logo, identiti pihak ketiga atau imej contoh ini. Untuk penerbitan semula atau kegunaan selain rujukan projek, dapatkan izin pemegang hak berkenaan. Kebenaran pemberi contoh bukan pengesahan semua hak pihak ketiga.
