# Buku Program AI

Pakej arahan untuk menyediakan buku program melalui perbualan AI, bukan automasi pelayar atau pemasang skill ChatGPT.

## Cara menggunakan

Baca dan ikuti `PROMPT-BUKU-PROGRAM.txt` dalam folder yang sama. Dalam ChatGPT, cara paling mudah ialah menyalin seluruh kandungan fail itu sebagai mesej pertama. Jika menggunakan lampiran TXT, sertakan arahan jelas supaya mengikutinya. Jangan menganggap fail ini dipasang secara automatik hanya kerana ia dinamakan SKILL.md.

## Aliran wajib

Contoh atau persetujuan tanpa contoh → tema → maklumat program → pengesahan kandungan dan panel → helaian luar → kelulusan → helaian dalam → semakan dan penyerahan.

## Fail sokongan

- `templates/maklumat-program.txt`: borang kandungan.
- `examples/program-rekaan.txt`: contoh rekaan, bukan acara sebenar.
- `CHECKLIST.md`: semakan hasil dan cetakan.
- `EVALUATION.md`: senario ujian tingkah laku dan had pengujian.

Arahan perbualan berada dalam fail prompt supaya satu sumber boleh diselenggara. Jangan gunakan data peribadi atau aset daripada komputer pencipta. Tiada kebergantungan kepada Hermes untuk pengguna biasa.
