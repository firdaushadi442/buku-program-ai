# Polisi privasi — Buku Program AI

## Skop dan pengendali
Pakej arahan ini diselenggara oleh pemilik repo Buku Program AI. Saluran sokongan: https://github.com/firdaushadi442/buku-program-ai/issues . Untuk isu privasi, jangan sertakan data sebenar dalam issue awam; minta saluran peribadi dahulu.

## Kategori data dan tujuan
Maklumat minimum ialah tajuk acara, tarikh, masa, tempat acara dan kandungan program untuk susun atur. Nama serta gelaran tetamu/jawatankuasa adalah pilihan dan hanya digunakan apabila perlu dan dibenarkan untuk penerbitan. Jangan berikan alamat rumah, lokasi GPS, nombor telefon peribadi, data murid atau tandatangan. Ringkasan teks tersunting mencukupi; kertas kerja penuh bukan syarat.

Jangan hantar data kad pembayaran, rekod kesihatan dilindungi, nombor pengenalan kerajaan, kata laluan, API key, kod OTP/MFA atau rahsia pengesahan. Data peribadi sensitif lain tidak diperlukan untuk tujuan plugin ini. Jika sumber mengandungi data itu, padam di sumber sebelum menggunakannya; jangan tampal semula data tersebut dalam permintaan sokongan.

## Penerima dan pemindahan
Pakej ini tiada backend pembangun, pelayan MCP, analitik, stor pengguna atau telemetri sendiri. Pembangun tidak menerima mesej atau fail perbualan melalui pakej ini. OpenAI atau penyedia klien memproses input dan output mengikut polisi serta tetapan akaun mereka. Jika anda menghantar issue atau mesej sokongan, GitHub dan penyelenggara menerima kandungan yang anda pilih untuk dihantar; issue awam juga dapat dibaca orang ramai.

Tiada pemindahan automatik kandungan acara kepada GitHub, Drive atau perkhidmatan lain. Tiada penjejakan, pengiklanan atau pemprofilan tingkah laku ditambah oleh pakej ini. Pemprosesan platform sendiri berada di bawah kawalan penyedia platform, bukan pakej ini.

## Tempoh penyimpanan
Pakej ini tidak menyimpan salinan input pada backend pembangun: tempoh simpanan backend plugin ialah tiada. Fail hasil yang disimpan oleh pengguna kekal sehingga pengguna memadamkannya. Retensi perbualan dan lampiran oleh OpenAI/klien mengikuti polisi dan tetapan akaun mereka; plugin tidak menetapkan atau menjamin tempoh itu.

Issue dan komen sokongan boleh kekal sepanjang repo/issue wujud sehingga dipadam oleh penulis atau penyelenggara apabila dibenarkan GitHub. Tiada jaminan penghapusan salinan awam, cache atau sejarah oleh pihak ketiga. Jangan gunakan issue awam untuk data peribadi.

## Kawalan pengguna
Anda boleh tidak memberikan nama pilihan, menggunakan nama dummy, meredaksi lampiran, berhenti menggunakan plugin, memadam fail setempat dan menyahpasang plugin melalui klien. Gunakan kawalan data/perbualan penyedia platform untuk permintaan pemadaman atau tetapan latihan yang tersedia. Anda boleh memadam komen sendiri atau meminta penyelenggara membuang kandungan sokongan melalui saluran repo tanpa mengulang data sensitif tersebut.

## Perubahan skop
Penambahan backend, analitik atau penerima baharu memerlukan polisi dikemas kini dan pendedahan sebelum pengumpulan berlaku. Polisi ini bukan jaminan atau pengganti polisi OpenAI dan GitHub.
